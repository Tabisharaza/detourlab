# Third-party notices and provenance

The current application has no third-party npm dependencies, external fonts, imagery, map tiles, geographic data or copied application code.

The street grid, river, buildings, vehicle jobs and scenarios are original procedural synthetic data distributed under the application's MIT license. They do not depict Riyadh or any real city.

Node.js and the visitor's browser are separately licensed runtime software, not vendored into this source bundle. The prepared GitHub workflow references official `actions/checkout` and `actions/setup-node` by full commit SHA; their code is not vendored here. See docs/CI.md for source links and pin provenance.
