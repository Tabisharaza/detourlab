    DETOURLAB / FIELD GUIDE

    Rehearse the disruption.

    DetourLab is a small, inspectable logistics laboratory. Close a road, replay exactly the same demand, and see the consequences of that single change.

    01. Change the network

    Choose a named variant, then set its closures. Duplicate it to compare a different plan. Each event has its own cutoff, and the road dropdown offers direction-aware keyboard editing.

    02. Replay the outcome

    All variant cards compare against one open-network baseline. Select any result to inspect its route at the same playback time. Top-line metrics cover the entire run, not just playback time.

    03. Follow the evidence

    Pick any vehicle to inspect its route and delivery outcomes. Export the whole versioned experiment as portable JSON and run it in Node to reproduce every variant and regression threshold.

    04. Know the limits

    Every street, vehicle and order here is synthetic. Travel times are fixed assumptions. This is a network-disruption experiment, not traffic prediction or an optimal vehicle-routing solver.

    Engine rules

    • Each variant shares exactly the same vehicles and ordered demand. Each vehicle keeps its assigned delivery order. Routes minimize assumed travel time with stable tie-breaking.
    • Closures are permanent from their start time. A vehicle already on a closing road finishes that edge, then reroutes at the next node.
    • An unreachable stop is skipped and recorded. The vehicle stays at its current node and attempts the next assigned stop.
    • Due times are arrival deadlines. Service time delays the next delivery; it does not change whether the current arrival is late.
    • No congestion, capacity, collision, break, traffic-signal, return-to-depot or real-world forecast model is included.

    Original synthetic geometry and application code. No map tiles, external fonts, analytics or API calls.
